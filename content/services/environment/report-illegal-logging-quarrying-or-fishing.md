# Report Illegal Logging, Quarrying or Fishing — Municipality of Aringay

Report **illegal logging, quarrying (quarry/hakot), or fishing** (dynamite, cyanide, fine-mesh, intrusion in municipal waters) in the **24 barangays, Aringay River, Lingayen Gulf (municipal waters: 15 km from shoreline)** via **MENRO + PNP + Bantay Dagat**.

---

## What You Need to Know

| Information         | Details                                                                                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Where to Report** | **MENRO, Municipal Hall** + **Barangay Hall** → endorsed to **PNP Aringay / Philippine Coast Guard / BFAR I / DENR-CENRO San Fernando** as appropriate |
| **When**            | ASAP — 24/7 via barangay/PNP hotline for active violation; office hours for follow-up                                                                  |
| **Cost**            | Free — anonymous accepted, but contact helps follow-up                                                                                                 |
| **Who**             | Any witness — fisherfolk in Dulao/Samara/San Eugenio highly encouraged                                                                                 |

---

## What to Report

| Violation             | Examples in Aringay                                                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Illegal logging**   | Cutting without DENR permit (upland Basca/Gallano forest patches)                                                                                |
| **Illegal quarrying** | Sand/gravel extraction from **Aringay River** without permit (DENR-MGB/Provincial)                                                               |
| **Illegal fishing**   | **Municipal waters:** dynamite, cyanide, fine-mesh _baling_, compressor, intrusion of commercial vessels within 15 km; **River:** electrofishing |

---

## How to Report

1. **Safety first — do not confront** — observe from distance
2. **Note details:** date/time, exact **sitio/purok**, barangay, landmark, number of persons/boat description (color, banca name, engine), plate/boat number, photos/video if safe
3. **Call immediately:**
   - **Barangay Hall / Bantay Dagat** (coastal barangays Dulao/Samara) or
   - **MENRO, Municipal Hall — (072) 607-9531** — ask for MENRO
   - **PNP Aringay — Municipal Police Station** (near Municipal Hall) — for active enforcement
4. **Formal blotter (if needed):** MENRO/PNP will ask you to **fill blotter + affidavit** for case filing with **DENR-CENRO San Fernando** (logging/quarrying) or **BFAR I** (fishing)

---

## What Happens After

- **MENRO/Bantay Dagat/PNP** verifies + patrols; DENR-CENRO/BFAR deputizes if needed → **apprehension + confiscation** per **Forestry Code, Mining Act, Fisheries Code (RA 10654)**
- Reporter may be called as **witness** (with protection per PNP/DENR)

---

## Penalties Reminder

- Logging/quarrying/fishing violations carry **fines + imprisonment** under PH laws + local ordinances — depends on scale and prior offenses.
