# Relocation Sites — Municipality of Aringay

Check available **relocation sites** if affected by **demolition, river/coastal clearing, road widening, or disaster displacement** — via **MSWDO + MPDC + Office of the Mayor**, Municipal Hall, Marcos Ave.

---

## What You Need to Know

| Information | Details                                                                                                        |
| ----------- | -------------------------------------------------------------------------------------------------------------- |
| **Where**   | **MSWDO / MPDC, Municipal Hall, Marcos Ave, Poblacion**                                                        |
| **When**    | Year-round inquiry; sites only available when LGU/Provincial/NHA project is open — MSWDO keeps **master list** |
| **Cost**    | Inquiry free; if awarded: **subsidized terms** per DHSUD/NHA/provincial                                        |
| **Who**     | Families with **demolition notice / danger zone tag / disaster displacement** — Aringay residents              |

---

## How to Check

1. **Visit MSWDO / MPDC, Municipal Hall** — bring **Barangay Certificate + valid ID + notice (if any: demolition / hazard tag from MDRRMO)** → fill **Relocation Inquiry Form**
2. **MSWDO case study** + **MPDC/LGU hazard mapping check** — verifies if your current dwelling is in **legal easement** (Aringay River 3m / coastal salvage 20m), **road right-of-way**, or **hazard zone** (flood/landslide)
3. **MSWDO advises:** whether there is **current site** (LGU/provincial/NHA) with vacancies, **pipeline site**, or **referral** to **on-site upgrading** (if not required to relocate)
4. **If site available:** MSWDO endorses to **DHSUD/NHA/Provincial Housing** for **screening**

> As of 2026, **no large within-Aringay NHA relocation site** is advertised — families are **waitlisted** and may be offered **provincial sites** (San Fernando corridor) or **in-situ assistance** depending on case.

---

## If No Site Currently

- You remain on **LGU Housing Master List** — MSWDO calls when intake opens (watch `facebook.com/betteraringay` + barangay hall)
- **Interim measures:** **MSWDO cash/material aid** (if calamity), **MDRRMO** safe return guidance, **MPDC** zoning advice for **temporary shelter**
