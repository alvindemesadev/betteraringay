# Zoning, Land Use & Building Permits — Municipality of Aringay

Secure **Locational Clearance / Zoning Certificate** from **MPDC** and **Building Permit** from **Municipal Engineering Office (MEO)** before construction — required in all 24 barangays.

---

## What You Need to Know

| Information | Details                                                                                                                                             |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Where**   | **MPDC (Municipal Planning & Development Coordinator), 2nd Floor, Municipal Hall** → **MEO, Municipal Hall**, Marcos Ave, Poblacion                 |
| **When**    | Mon–Fri 8AM–5PM; apply **before** any construction/renovation                                                                                       |
| **Cost**    | Zoning fee + Building Permit fees based on floor area/value per National Building Code + local fees — pay at **Municipal Treasurer's Office (MTO)** |
| **Who**     | Lot owners, lessees with lessor consent, contractors                                                                                                |

## Process (Two Steps: Zoning → Building Permit)

### Step 1: Zoning / Locational Clearance (MPDC)

**Purpose:** Conform to **Aringay Comprehensive Land Use Plan (CLUP) & Zoning Ordinance** (Sangguniang Bayan) — residential, commercial, agricultural, coastal easement, flood hazard zones.

**Requirements:**

- Filled **Application for Locational Clearance** (MPDC form)
- **Transfer Certificate of Title (TCT) / Tax Declaration + Deed of Sale / Lease Contract + Lessor's Consent** (if not owner)
- **Barangay Clearance** (for construction — from barangay hall)
- **Sketch/Location map** + **Vicinity map**
- **Building Plans** (if available at this stage — 2 sets, not yet signed/needed for building permit next)
- Lot plan / survey (if available)

MPDC evaluates **use vs zone** (e.g., no commercial in agricultural without reclassification; no building within **river easement / 20m coastal salvage zone**). If compliant, MPDC issues **Locational Clearance / Zoning Certificate** (1–3 days).

### Step 2: Building Permit (MEO)

**Requirements (per NBCP):**

- **Locational Clearance** from MPDC (Step 1)
- **Building Plans + Structural/Plumbing/Electrical** — signed & sealed by **licensed architect/civil engineer**
- **Bill of Materials + Cost Estimates**
- **Barangay Clearance** (construction)
- **Fire Safety Evaluation Clearance (FSEC)** from **BFP Aringay** (MEO routes)
- **Sanitary / Health** clearance if with septic/water (MHO)
- Other: **Homeowner's Assoc. clearance** (if subdivision), **Environmental** if needed (MENRO)

**Steps:**

1. Submit to **MEO front desk** → pre-screening → routed to **MPDC (if not yet), BFP, MHO, MENRO** as applicable
2. **Assessment** — MEO computes **permit fees, fire code fees**, etc. → **Pay at MTO** (Treasurer)
3. **Issuance** — **Building Permit** + **FENCED & posted at site** before construction

> **No permit, no construction** — per Sangguniang Bayan ordinance + National Building Code. Occupancy Permit required **after** construction before occupying (return to MEO with completion + inspection).

---

## After Building Permit

- **Occupancy Permit** — after final inspection by **MEO + BFP**
- **Certificate of Occupancy** needed for **business permit, water/power connection, occupancy**
